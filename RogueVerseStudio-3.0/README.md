# RogueVerse Studio Website 3.0
Static GitHub Pages website for RogueVerse Studio, RogueVerse Mythra, RogueVerse News, and Square Shop access.

## Publish
Upload the contents of this folder to the root of the GitHub repository. In Settings > Pages, deploy from the `main` branch and `/(root)`.

## Add manga pages
Place optimized WebP/JPEG pages in `assets/manga/<series>/<issue>/`, then replace the placeholders in the reader HTML with `<img>` tags. Export web copies with the watermark permanently embedded for stronger protection.

## Square shop
Replace every `https://squareup.com/store/your-store` placeholder with the actual Square Online store or payment link.
