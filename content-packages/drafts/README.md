# Draft packages

Create three complete package JSON files here each week. Start from
`content-packages/examples/faceless-package.example.json`.

Recommended Eastern Time cadence:

- Monday: AniManga / Old Man Otaku
- Wednesday: Movies and culture
- Friday: Future technology

Drafts do not publish. Run the **Prepare content package for approval** workflow
with the draft path. The workflow generates the article, feed/index updates,
sitemap, robots file, social metadata, and a 9:16 approval video in a pull
request. Merging that pull request is the approval event.
