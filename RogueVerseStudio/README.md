# RogueVerse Studio Website

Complete current static website package for GitHub Pages.

## Included sections
- Homepage
- RVS News
  - RVS Movies
  - RVS Games
  - RVS Animanga
- RVS Publishing
- RogueVerse Studio: Mythra
  - Sentou
  - Love × Power
  - Stranded in a Bounty Hunter World
- In-browser manga reader with a light ownership watermark
- RVS Future
- Mission Statement placeholder
- Our Story
- Square Shop placeholder

## Deployment
Upload the contents of this folder to the root of the `main` branch in the
`RogueVerse-Studio/RogueVerseStudio` repository.

GitHub Pages should use:
- Source: Deploy from a branch
- Branch: main
- Folder: /(root)

## Shop
Replace `#` in `SHOP_URL` inside `script.js` with the full Square store URL.
