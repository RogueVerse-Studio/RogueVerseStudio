# RogueVerse Studio website

Static GitHub Pages website for RogueVerse Studio, RVS News, RVS Publishing, and RVS Mythra.

## Publish with GitHub Desktop

1. Copy everything in this folder into the local `RogueVerseStudio` repository.
2. In GitHub Desktop, enter the summary `Build first RogueVerse Studio website`.
3. Click **Commit to main**, then **Push origin**.
4. On GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main**, folder **/(root)**, and click **Save**.

The project site will appear at:

`https://YOUR-GITHUB-USERNAME.github.io/RogueVerseStudio/`

## Before launch

- Replace `SHOP_URL` in `script.js` with the full Square shop URL.
- Replace the temporary `RV` mark with the official RogueVerse Studio emblem when ready.
- Replace each placeholder `.manga-page` in `mythra/reader.html` with a real `<img>` element.
- Export manga pages as optimized JPG or WebP files and add the light ownership watermark before upload.
